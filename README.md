# load_for_post.py — выгрузка утверждённых документов с ГИС ЦАП Административное производство (lks.dap.gov.ru)

Скрипт выгружает утверждённые PDF (Извещение / Протокол / Определение / Постановление) 
за заданную дату и готовит их для отправки через систему электронных писем Почты РФ.

## Установка

Требуется Python 3.8+. 

Для второй (почтовой) стадии:
```bash
pip install pypdf pdfplumber openpyxl pikepdf
```

## Настройка — `config.json`

Создаем файл config.json, рядом со скриптом.

| Поле             | Обязательно | Описание                                              |
|------------------|-------------|-------------------------------------------------------|
| `login`          | да          | Логин для входа на lks.dap.gov.ru                     |
| `password`       | да          | Пароль                                                |
| `sender_address` | нет         | Адрес отправителя для реестра; без него используется  | 
|                  |             | адрес из Брянскстата по умолчанию                     |

Пример структуры:

```json
{
  "login": "<логин>",
  "password": "<пароль>",
  "sender_address": "241030, БРЯНСКАЯ обл., г. БРЯНСК, ул. КРАСНОАРМЕЙСКАЯ, д. 60"
}
```
На Windows cохраняем файл "config.json" в кодировке ANSI


## Использование

```bash
python3 load_for_post.py [ДД.ММ.ГГГГ]
```

- дата в аргументе — дата **утверждения** (по умолчанию — сегодня);
- флаги не используются: скрипт последовательно выполняет обе стадии (выгрузка → почтовые пакеты).

## Что делает скрипт

**Стадия 1 — выгрузка.** Получает список утверждённых документов за дату,
скачивает «Печатную форму» (финальный PDF со штампом ЭП) и XML-форму
в `out/<ДД.ММ.ГГГГ>/<тип>/`. «Подтверждения вручения» и
«письма-уведомления о документе» не сохраняются.

**Стадия 2 — почтовая.** Для каждого PDF определяет получателя
(ФИО или название юрлица, ИНН, адрес — из текста PDF и XML-формы),
сливает документы на одного получателя в один PDF (`[ИНН].pdf`),
заполняет реестр `registry.xlsx` по формату из `registry.md`
(первая строка — имена полей; заполняются FILE_NAME, ADDRESSLINE_TO (без индекса),
RECIPIENT_TYPE, RECIPIENT, LETTER_REG_NUMBER (нумерация с 1), MAILCATEGORY=1,
ADDRESSLINE_RETURN, INN, LETTER_TITLE (типы документов через запятую),
WOMAILRANK=0, NO_RETURN=1; SNILS, КПП и доп. поля не заполняются)
и упаковывает
в архивы `out/<ДД.ММ.ГГГГ>/post1.zip, post2.zip, ...`
(не более 1000 писем в архиве; в каждом архиве — свой `registry.xlsx` и его PDF).
Исходники (из стадии 1) удаляются, в каталоге даты остаются только `post*.zip`.

Архивы и реестры готовы к загрузке в систему электронных писем Почты РФ.
